Lotus & Co. 🌸
Este proyecto consiste en el desarrollo de una página web para Lotus & Co., una propuesta visual en la que se busca transmitir una identidad estética, delicada y moderna a través de su diseño.

Durante su desarrollo se trabajó en la estructura de la página, la organización de los elementos, los estilos, las imágenes y la adaptación del sitio para que pueda visualizarse tanto en computadoras como en dispositivos móviles.

Para su creación se utilizaron HTML y CSS, buscando lograr una presentación agradable, ordenada y fácil de navegar.

Este trabajo representa lo aprendido durante el desarrollo y diseño de páginas web.
